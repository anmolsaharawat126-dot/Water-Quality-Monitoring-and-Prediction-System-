# Water Quality Monitoring & Prediction System

## Overview
A Python-based system for monitoring and analyzing water quality parameters such as pH, turbidity, dissolved oxygen, and heavy metal concentration.

## Features
- Water Quality Analysis
- pH Monitoring
- Turbidity Check
- Dissolved Oxygen Analysis
- Water Safety Classification

## Tech Stack
- Python
- Pandas
- NumPy
- Scikit-Learn
- Streamlit

- ## Results
- Real-time water quality analysis
- Safe / Unsafe water classification
- Parameter-based monitoring system
